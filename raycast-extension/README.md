# Remr for Raycast

A Raycast command for remr: **Agenda** opens remr's calendar from Raycast by calling
the `remr://calendar` URL scheme. remr needs to be installed (`./install.sh` at the
repo root) for the scheme to resolve.

## Develop locally

1. Install Node.js and Raycast's developer tools.
2. From this directory, run `npm install` then `npm run dev`.
3. Search Raycast for **Agenda**.

This is a local extension project and is not yet published to the Raycast Store.
